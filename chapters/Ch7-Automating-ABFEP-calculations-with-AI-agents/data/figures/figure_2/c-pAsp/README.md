# Figure 2C: pAsp parameterization

`make_figure_2c.py` renders the complete pAsp-containing pentapeptide in PyMOL using
the matte-stick style of Figures 2a and 2b. Peptide carbons are green (#A0D568),
pAsp side-chain carbons cyan (#4FC1E8), oxygens red (#ED5564), nitrogens blue,
and phosphorus gold (#FFCE54). Stick radius (0.23 angstrom), diffuse lighting,
and the absence of specular highlights match the other panels.
It reads the successful run's `peptide.gro` and `topol.top`, retaining all five
residues: PHE577–SER578–D2P579–LYS580–THR581. The GRO contains 86 atoms; all 46
heavy atoms are shown and the hydrogens are hidden. PyMOL converts GRO coordinates
from nm to angstroms, followed by a rigid camera rotation. The conformation is
preserved. This is the topology-built peptide before solvation and equilibration.

Run with Python, PyMOL (`pymol2`), NumPy and Matplotlib:

```bash
python make_figure_2c.py
```

For the existing environments on this machine, run from the manuscript root:

```bash
PYTHONPATH=/tmp/mdarena-pymol-venv/lib/python3.12/site-packages \
MPLCONFIGDIR=/tmp/mdarena-matplotlib \
../MDArena-dev/.venv/bin/python figures/figure_2/c-pAsp/make_figure_2c.py
```

Outputs are saved beside the script: `figure_2c.png` (600 dpi), `figure_2c.pdf`,
`figure_2c.svg`, `pasp_clean.png` (clean PyMOL render), `pasp.png` (molecule and
torsion markers), and `pasp.pse` (editable PyMOL session with torsion leaders
and labels). The figure contains only the peptide and torsion annotations;
titles, atom labels, legends and parameter text are omitted. The session's
torsion annotation group can be hidden independently. PDF/SVG text is editable;
the molecular rendering is embedded as
a raster image. `VIEW` stores the exact user-supplied PyMOL `get_view`, including
its perspective setting and clipping planes. The native images are 3200 × 2400
pixels; the panel bounds fit the complete peptide in the selected view. Annotation
positions use the same perspective projection. `VIEW`, colors, dimensions and annotation
positions can be changed in the script.

## Torsion assignments

Gray markers identify inherited CHARMM36 torsion axes: phi, psi, the two flanking
peptide omegas, chi1 (CA–CB), and chi2 (CB–CG). The topology also retains the
standard improper terms and backbone CMAP. Each marker identifies a bond axis;
several atom quartets can share that axis.

The labels **tau1** and **tau2** are local figure labels for the two axes with
added pAsp-specific proper torsion parameters:

| Label | Atom quartets | Fourier terms per quartet, in GROMACS units |
| --- | --- | --- |
| tau1 | CB–CG–OD2–P; OD1–CG–OD2–P | (n, phase, K): (1, 180°, 41.84000), (2, 180°, 9.41400), (3, 180°, 5.69024) |
| tau2 | CG–OD2–P–OP1; CG–OD2–P–OP2; CG–OD2–P–OP3 | (n, phase, K): (3, 0°, 0.41840) |

K is in kJ/mol, for `K [1 + cos(n theta - phase)]`. These are the parameters
provided by the task from Damjanovic et al. (2009), DOI 10.1002/prot.22439,
converted and implemented by the run. The figure does not represent a new fit.
The script checks all five residue identities, the input's 86 atoms, the rendered
46 heavy atoms, D2P's −2e charge, all five added proper torsion quartets, and the
existence of every labeled central bond in the topology.

## Other parameter assignments

The source topology assigns the following types and charges, documented here
without adding atom labels to the figure:

| Atom | CHARMM type | Charge (e) |
| --- | --- | --- |
| CB | CT2 | −0.18 |
| CG | CD | +0.51 |
| OD1 | OB | −0.51 |
| OD2 | ON2 | −0.40 |
| P | P | +1.10 |
| OP1 | ON3 | −0.90 |
| OP2 | ON3 | −0.90 |
| OP3 | ON3 | −0.90 |

The source includes the added CG–OD2 bond term and the three angle terms used
by D2P: CB–CG–OD2, OD1–CG–OD2, and CG–OD2–P. The supplied extension additionally
includes the CT3–CD–ON2 angle analogue; this residue uses CT2 at CB.
The included `phosphoasp.itp` gives their numerical parameters.
