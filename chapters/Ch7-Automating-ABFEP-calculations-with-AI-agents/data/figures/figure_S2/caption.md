**Figure S2. Task-level strict success across all twelve repeatedly evaluated configurations.**
Each cell gives the number of strict passes out of three selected replicates
for one task and configuration: beige, ochre, light teal and dark teal denote
0/3, 1/3, 2/3 and 3/3, respectively. A strict pass requires a completed trial
with full correctness and process scores; execution errors contribute no strict
pass. These are counts across three replicates, not partial-credit scores or
the binary task-level Pass@3 outcome. Rows retain the benchmark task identifiers
and short scientific descriptions, grouped by the seven existing task types;
the letters E, M and H denote easy, medium and hard difficulty. Configuration
names label columns, and task types appear at the right. The footer's reference
to the same row order in “both versions” concerns the companion five- and
twelve-configuration analysis heatmaps; the twelve-configuration version alone
is reproduced here. Results use the finalized manuscript selection and Task 39
Policy B harmonization. This figure is copied unchanged from the existing
post-harmonization analysis, including all labels, colors and annotations.
