## Plotting

From the thesis repository root:

```sh
uv sync --locked
chapter=chapters/Ch7-Automating-ABFEP-calculations-with-AI-agents
uv run --locked python "$chapter/scripts/make_figure_3.py"
```

This reads `data/headline.csv` and `data/metrics/` within this chapter and writes
`figures/figure_3/figure_3.pdf` and `.png`. The scripts resolve paths relative
to their own location, so the working directory does not affect asset paths.

The plotting environment supports these generators:

Thesis Figure 7.9 is generated separately from its dedicated figure folder:

```sh
uv run --locked python "$chapter/figures/figure_7_9/make_figure_7_9.py"
```

It writes `figure_7_9.{pdf,png,svg}` beside the script. Panels A and B use the
cohort medians reported in the chapter text; panel C reads the five models'
`data/trials/` tables and applies the same failure classification as Figure A1.
The figure uses uppercase panel labels, embedded PDF fonts, and 600 dpi PNGs.
The untitled legend is stacked vertically inside panel C's upper-right corner,
with the labels "Evaluation", "Timeout", and "Runtime error" in black and no
border. Failed evaluation uses Verdigris (`#2a9d8f`),
agent timeout uses Jasmine (`#e9c46a`), and other runtime error uses Burnt Peach
(`#e76f51`).

Figure 1 uses the copied task metadata by default. Set `MDARENA_REPO` to a full
benchmark checkout to use a different task metadata source.

Figure 2's SVG assembly script requires the Inkscape command. Molecular rendering
and preparation scripts also require tools from the upstream scientific
environment, including PyMOL, RDKit, or GROMACS. Figure 5's preparation and
validation scripts depend on original job records and source-specific audit
checks. These tools are separate from the thesis plotting dependencies; Figure
5 can be plotted directly using its copied data, prepared coordinates under
`scripts/intermediates/figure_5/derived/`, and existing renders. Its molecular
renderer is `scripts/render_figure_5_structures.py`.

For the Figure 2 RBFE panels, run `make_solvent_leg_structures.py` before
`make_complex_leg_structures.py`; both write prepared PDBs to
`scripts/intermediates/figure_2/a-RBFE/`. The image generators read those working
files, including the retained manually edited complex PDBs, and write PNGs to
`figures/figure_2/a-RBFE/`. All molecular renderers save their editable `.pse`
sessions under the corresponding `scripts/intermediates/` folder.

The imported README files, captions, reports, and JSON/CSV manifests inside
`data/` and `scripts/intermediates/` retain the source project's historical paths
and hashes. Use this README for current commands and `data/source_manifest.csv`
for the current destination of each retained imported file.
